## Intent

The fixture's deliberately large, unrelated Spec — no connection to
SPEC-100/101/102 — used for the "large specification" evaluation case
(spec FR-010) and as a forbidden identifier in the forbidden-content
evaluation case (it must never appear in a Context Pack requested for
an unrelated target).

## Background

This section exists purely to make SPEC-103 large enough to be a
meaningful "large specification" fixture case, independent of any
other Spec in this fixture project.

Paragraph one covers scope: this Spec intentionally repeats similar
prose across several headings so its own token count is substantially
larger than SPEC-100, SPEC-101, or SPEC-102, without introducing any
real dependency or wikilink relationship to them.

Paragraph two covers rationale: a genuinely large fixture Spec is
necessary to exercise budget/estimator code paths realistically,
rather than relying only on small, artificially minimal fixtures.

## Constraints

Paragraph three covers constraints: this Spec must remain entirely
disconnected from SPEC-100 through SPEC-102 so it is safe to use as a
"forbidden" identifier in an evaluation case whose target is one of
those unrelated Specs.

Paragraph four repeats the same theme in different words, to add bulk
without changing the Spec's actual meaning: this Spec has no
dependencies, no wikilinks, and no backlinks to any other fixture
entity in this evaluation project.

## Verification

Paragraph five: verification for this Spec, within this fixture, is
simply that it is large relative to its siblings and that it never
appears in a Context Pack requested for a target it has no relation
to.

## Notes

Paragraph six: no further notes beyond confirming this Spec's
deliberate size and isolation within the fixture project.
